# Binary asset handling

The source repository is being populated through the ChatGPT GitHub connector, whose file-content action accepts UTF-8 text but not direct local binary file references. Approved binary assets are therefore retained in the project artifact package and should be copied into this directory as their native files when cloning/importing the complete project package.

Expected native files:
- `homeflow-ai-logo.png`
- `pyrneo-logo-wordmark.png`
- `presentations/HomeFlow_AI_by_Pyrneo_Presentation.pptx`

The application source does not depend on these binaries to run the MVP dashboard; they are presentation/brand assets.
