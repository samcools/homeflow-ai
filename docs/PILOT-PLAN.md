# 90-Day Pilot Plan

## Phase 1 — Discover & Configure (Days 1–30)
- select one province or municipality
- identify 10–20 representative projects
- map source data and reporting cycles
- configure users, roles and project-health rules
- establish data-governance and security baseline

## Phase 2 — Activate & Train (Days 31–60)
- train officials
- activate project, risk, evidence and recovery workflows
- run AI monitoring in advisory mode
- collect user feedback and tune thresholds

## Phase 3 — Measure & Scale (Days 61–90)
- assess intervention lead time, action closure, data completeness and decision quality
- review AI recommendations and overrides
- refine operating model
- define integration and scale roadmap

No outcome improvement should be claimed until measured against an agreed baseline.
