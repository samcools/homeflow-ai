# POPIA Design Notes

HomeFlow AI is designed around purpose limitation and data minimisation.

- Executive views should use aggregate delivery data by default.
- Beneficiary-identifiable data should be separated from project-management data and exposed only to authorised roles.
- AI requests should contain only the minimum fields needed to answer a question.
- Retention periods must be configurable by information category.
- Access, change and export activity should be logged.
- Production deployments require a documented lawful-processing basis, operator agreements where applicable, retention schedules, incident procedures and data-subject request handling.
