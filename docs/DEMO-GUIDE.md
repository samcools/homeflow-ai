# Hackathon Demo Guide

## Story
HomeFlow AI helps officials move from **knowing a project is in trouble** to **coordinating accountable recovery**.

## Recommended flow
1. Start on Command Centre and show portfolio metrics.
2. Click **Analyse priorities**.
3. Open `HF-102` and compare expenditure to physical progress.
4. Ask the Copilot: **Why is this project at risk?**
5. Explain the evidence-grounded health drivers and confidence.
6. Ask: **Which project has the largest budget-to-progress gap?**
7. Demonstrate voice input: **Which projects require my attention today?**
8. Generate the Executive Brief.
9. Reinforce responsible AI: recommendations require official review.

## Judge takeaway
**Data → Intelligence → Action → Accountability → Impact**
