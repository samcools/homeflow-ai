# Test Plan

Before a public demonstration verify:
- API health responds
- dashboard and project data load
- portfolio filtering works
- project selection updates health panel
- AI copilot returns grounded responses
- voice input works in a supported browser
- speech output does not overlap previous audio
- responsive layouts work at desktop/tablet/mobile widths
- consequential action endpoint requires confirmation
- no secret is present in the web bundle
- all demo records are clearly synthetic

Production readiness additionally requires security, accessibility, integration, load, backup/restore and disaster-recovery testing.
