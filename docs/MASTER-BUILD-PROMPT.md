# HomeFlow AI Master Build Directive

Use Project Guardian as the functional baseline and preserve its project management, milestone, work-item, activity, audit, AI assistant, voice and responsive experience. Extend it into a Human Settlements Delivery Assurance Platform with:

- Executive Control Tower
- explainable AI Project Health Score
- early-warning engine
- budget vs physical progress intelligence
- housing unit delivery tracking
- contractor performance
- site evidence and inspections
- stalled-project signals
- recovery-plan orchestration
- GIS delivery intelligence
- multilingual voice AI
- executive briefing and “What Changed?” analysis
- Responsible AI and human approval gates
- POPIA-aware information architecture
- Microsoft-aligned Azure target architecture
- API-first government-system integration

North-star question: **Does this help government move from knowing that a housing project is in trouble to actually getting that project delivered?**

## Product philosophy
**Monitor → Anticipate → Explain → Act → Escalate → Verify → Learn**

## Delivery rule
Do not remove stable Project Guardian functionality. Do not claim integrations, deployments, validation or testing that have not actually been completed. Use synthetic data for the hackathon unless a verified and authorised source is connected.
